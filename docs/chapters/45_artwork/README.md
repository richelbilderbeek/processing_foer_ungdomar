# 45. Artwork

Inte all programmerare gillar att skapa graphics
för sina spel.

Här lära vi att använda artwork av andra.

## 45.1. Fri artwork

[https://kenney.nl/](https://kenney.nl/)
är en hemsida som har gratis artwork
som du får använda legalt utan att nämna dem.
Självklart, du **får** nämna dem, så att
dina kompisar också kan hitta den här hemsida

## 45.2. Slutuppgift

Skapa en programm som använder 2D artwork av
[https://kenney.nl/](https://kenney.nl/).
Har en länk någonstans till var du laddade ner artworken.
